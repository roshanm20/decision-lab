# Discovery log

One file per month. Every discovery day appends what the search turned up, whether or not it got built.

The format is three to five findings, each one line, with a link and a verdict: built, queued, or ignored with the reason. Queued findings go into `BACKLOG.md` so they are not lost.

This log is the part that shows what was considered and rejected, not just what got shipped. A month where twenty things were looked at and four were built is a better signal than four pieces appearing from nowhere.
