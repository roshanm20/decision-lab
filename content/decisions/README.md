# Decision records

Decisions from my own work, written up properly. CompEdge, Nayrix, the eval work, the analytics projects.

Each one is built from a rough note I wrote in `journal/inbox`, using only what that note contains. Where a record has open questions at the end, that is a gap in my own note, not a rhetorical device.

These are the pieces I can speak to in the most detail, because I was the one making the call.
